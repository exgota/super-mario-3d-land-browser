## Recovered behavior

The root computes four border dimensions and its origin through the unchanged helpers 0033CCF4 and 00215DA0. It prepares the content material, rebuilds cached coordinates when either the root cache flag or material bit 4 is clear, queues the content transform and expanded center rectangle, applies the supplied colors/alpha, and queues the center draw. It then installs local white colors with the same alpha for border pieces.

Frame count 1 uses one material and one sampled texture size for four edges, with orientations 0/1/4/2. A material whose low two format bits are zero returns early before the final flush check. Frame count 4 visits frames 0,1,3,2. Frame count 8 visits 0,6,1,5,3,7,2,4, drawing corners and intervening edges. Individual zero-format materials are skipped. Other counts draw only the center. A remaining queued draw triggers the original flush.

The source retains the floating operation order of each size/position expression. The C declaration returns void: the replay checks complete return and preserved state, not the unspecified caller-saved r0 value.
