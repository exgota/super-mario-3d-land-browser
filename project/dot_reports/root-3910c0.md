## Recovered behaviour

Disabled units clear their bit in cache+00 and return0. An enabled unit with no image data clears its bit and returns502. An invalid unit on this early path returns501; an enabled invalid unit with nonzero data still evaluates the border conversions and returns0.

Enabled units pack RGBA into the low-to-high bytes without adding a clamp. LOD bias becomes a signed 13-bit fixed-point value: zero and exponent255 map to0; other values are offset by16, multiplied by256, clamped to0..8191, then offset by4096 with 13-bit wrap. Floating exceptions and the original bitwise upper-bound test matter for extreme values.

Wrap enums2901/812D/812F/8370 encode2/1/0/3 in the S or T three-bit field. Unknown wraps leave their field unchanged. Magnification2600/2601 clears/sets bit1. Minification2600/2601 disables mip range;2700..2703 selects bit2, the mip-count-minus-one high nibble and clamped minimum-LOD nibble, and bit24. Unknown filters retain their fields.

Formats1906..190A,6700,675A and675B take the ordinary sampling path. Format675A also sets parameter field30 to20. Unit0 additionally accepts6040, with its forced parameter/wrap/LOD combination. Format6050 has a different special path for all units, preserving some existing parameter bits while clearing filters, LOD range, wrap fields and border. Unsupported formats return502 after the root's earlier partial cache writes; source preserves those partial updates. The first replay exposed an incorrect501 in that path, corrected in1610e9b before freezing results.

Unit0 writes border/dimensions/bias/format before validating the format. Units1/2 update bias and clear parameterC0 first, and only write border/dimensions/packed format after acceptance. Source preserves these order differences. Width and height retain only11 bits; the translated image address retains the old high two bits and ORs physicalAddress>>3.

The root calls the existing physical-address veneer00289C1C, which branches to named nn::gxlow::CTR::GetPhysicalAddr at0010B2C0. It calls existing __cb_writeRegs at00211DD8 with register/count81/10,91/6 or99/6 and a pointer directly into the cache. Unit0 then conditionally appends its format word and000F008E command to the existing cursor. Command-space exhaustion follows the original helper and root comparisons.

## Bounded replay and limits

Unicorn executes ARM1176/VFPv2 with the owner's entire unchanged code image mapped. Both runs execute the original00289C1C veneer, physical-address helper0010B2C0 and __cb_writeRegs00211DD8; no callee is modelled, skipped or stubbed. Each was entered6,578 times per run. The candidate image is an ordinary diagnostic armlink of the unchanged canonical object at00500000 with only independently established imports. This diagnostic image is not passed off as canonical equality.

Each of4,516 fixtures invokes its entry twice and compares the complete64KiB synthetic working region, cursor/end, root return status, cumulative FPSCR exception bits9F and normal return. All r4..r11, d8..d15 and SP canaries survive. The void caller's scratch return register is intentionally not compared. Fixture groups:

- 2,160 format/filter/wrap combinations across all three units
- 729 enable/address-translation/command-capacity cases
- 21 dimension/packed-field boundaries and4 invalid-unit paths
- 450 exceptional bias and450 exceptional border cases, including zeros, subnormals, finite extremes, infinities and quiet/signalling NaNs under default, FZ, DN and all three nondefault rounding modes

This is a constructed, single-threaded, mapped-buffer contract. It does not establish arbitrary pointer overlap, invalid-pointer/fault timing, racing command producers, actual GPU behaviour, every possible float bit pattern or every combined FPSCR mode. The observed caller aliases are included; general aliasing is not claimed. C++ float-to-unsigned conversions are validated as emitted ARMCC instructions in this environment, not as a portable all-platform overflow policy. Passing every target instruction is a coverage statement, not an all-path or all-input proof.
