## Independent identities and ABI

The predicates load the placement pointer from inputR0 field0, call accepted ByamlIter::isValid0x00276AA0 and signed integer-key reader0x0027E068, reject-1, then return whether the retained default/read identifier is nonnegative. Actor-init caller0x0015E34C passes its saved initialization argument to0x001CD794; Game callers0x00303824 and0x00309AC8 pass saved initialization records to0x00218B18 alongside already accepted fixed Boolean Arg helpers. These observations agree with the already established ActorInitInfo field0 layout. Original public API names are unknown.

The direct reader receives outputR0 and an eight-byte ByamlIter/AreaInitInfo placement-prefix addressR1. Named AreaObj::init0x0027E0A4 passes its input AreaInitInfo address unchanged to this reader, then uses the initialized identifier as the area shape selector. It stores-1 before validation. Validity/key failure or read value-1 leaves that initialized-1. Any other signed integer is stored and returns true, including other negative values.

The target literal words independently reference whole existing data rows0x003A2DBC–0x003A2DCC containing `ShapeModelNo` and0x003A2E30–0x003A2E40 containing `GenerateParent`, including terminators/padding. Proposed imports `dat_003A2DBC`, `dat_003A2E30` label those unchanged existing rows. No new data row or split is proposed.
