## Observable behavior and independent evidence

With a null matrix, the helper writes the supplied position's three float words into a borrowed context matrix's translation column at context +0x888/+0x898/+0x8A8, then passes that 3x4 matrix beginning at context +0x87C. Both paths call existing 0x002E54AC with context, reference, matrix, index, zero, low flag byte and -1. Its result is not consumed.

The separate entry constructor 0x001C5AB4 stores its incoming owner at entry +0, a newly allocated reference pointer at +4 and configuration at +8. It reads the signed configuration index at +8 and consults configuration +0 when the index is negative. The accepted reference-clear helper 0x001C5A88 independently follows entry +4 and establishes reference object +0/identifier +4. These establish owner/reference/configuration offsets independently of the target helper.

The independent transform/creation caller 0x0023F02C uses the established set configuration +0x0C, translation +0x10 and matrix +0x14. At 0x0023F080 it passes a null matrix and supplied position; at 0x0023F09C it passes null matrix and the set translation; at 0x0023F0DC it passes the set matrix and null position. Its configuration word at +0x0C supplies the incoming r3 flags. This supports a raw incoming word narrowed inside the callee and the matrix/position branch contract. The caller and its parked query imports are not revisited here.

The creation consumer 0x002E54AC is an existing mapped function interval (0x002E54AC..0x002E5984). It is larger than 0x400 and remains reserved for dot. It reads a context resource table at +4, uses the index to select a resource record, chooses an object from its context pool, writes the selected object pointer through the supplied reference at 0x002E55AC, and copies the supplied matrix into object transforms at +0x0FC/+0x12C via 0x0027C18C. These establish the reference output and matrix input roles. Only the helper's imported ABI is proposed. Original creation return type and full resource/context class names remain unknown; the caller ignores the return register.

No allocation, deletion or ownership transfer occurs in the proposed helper itself. Owner, reference, configuration, input matrix and position are borrowed. The context's existing temporary matrix is modified only in the null-matrix path. The helper does not initialize the remaining matrix elements or claim the full context layout.
