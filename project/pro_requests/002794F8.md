# Capped integer argument reader family

Ten existing U functions reached eight unchanged-flag C++ structural forms. None matches. Production is untouched and no NonMatching claim is made. The paired Boolean/float wrappers remain frozen separately.

All nine ActorInitInfo readers load the established placement pointer at offset 0, validate the ByamlIter via independently named 0x00276AA0, call signed integer key reader 0x0027E068, reject -1 and store one integer word only on success. The direct PlacementInfo Arg2 reader passes receiver R1 without the field load. Every function owns an 8-byte ArgN inline pool. Existing public integer generic argument and ActorInitInfo Arg3 declarations plus named float Arg0 anchor the numbered family; proposed names encode independently observed receiver/output/key identity. No new layout or pool import is proposed.

## Eight structural forms

| Form | Integer helper structure | Actor bytes/diff | Direct bytes/diff |
| --- | --- | --- | --- |
|1|Positive compound guard, write integer, return constants|92 /38|92 /38|
|2|False-initialized result, assign true on success, return result|88 /44|88 /44|
|3|Form1 with positive success/failure branch in each outer wrapper|88 /51|88 /51|
|4|Named combined status, conditional store, return status|84 /47|84 /47|
|5|Named combined status, conditional success return, constant failure|92 /38|92 /38|
|6|Named combined status, negative guard returns status, success returns true|84 /47|84 /47|
|7|Separate validity/completion flags, guarded store and success return|88 /33|88 /32|
|8|Separate validity/default flag, compound success and default false return|88 /33|88 /32|

Forms 1/5 preserve the complete 92-byte extent, but 38 bytes differ. Forms 7/8 have fewer differing bytes while missing four allocated bytes and cycling registers. Neither result counts as close enough. Form 8 Actor output places output/key/receiver/default status in R5/R6/R7/R4; target uses R4/R5/R6/R7. The generated return sequence is shorter and moves a temporary result to R0. Target materializes the default false value after the validity check and uses a shared epilogue with a separate true status and integer payload.
