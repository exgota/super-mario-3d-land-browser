# Native CGFX vertex and index records

Verified on 2026-10-01 with Apple Clang 21.0.0, C++20, AddressSanitizer and UndefinedBehaviorSanitizer. `runtime/AssetReader.cpp` remains outside Game/al and the ARMCC matching build. Its CGFX catalog now includes resource-local vertex attributes, index streams, serialized primitive topology, inline vector fields, raw skeleton records and model-local mesh/material identities. It does not apply a skeleton, shape or world transform, interpret material state or render a model.

The owner's selected files use CGFX revision 0x05000000. Their CMDL shape lists point to SOBJ records with flags 0x10000001. The documented count, self-relative pointer and stride fields lead to 0x40000002 interleaved vertex groups, 0x40000001 component declarations, face groups and index descriptors. Metadata stays inside DATA; vertex and index buffers stay inside the IMAG payload. The reader bounds those regions before traversal and limits decoded components by the source file size.

The public [CGFX description](https://www.3dbrew.org/wiki/CGFX) establishes the record layout. Its compact scalar-type table differs from this owner's variant, which stores OpenGL scalar enums. The [Khronos registry header](https://github.com/KhronosGroup/OpenGL-Registry/blob/main/api/GLES/gl.h) establishes those enum values. The reader handles float32, signed/unsigned byte and signed/unsigned short components. Each attribute retains its raw component words, multiplier bits and scaled float32 bits. Semantic IDs remain numeric, including unresolved semantic 2.

Independent Python reads compare every exposed field and component against the original extracted member bytes. All 39 model catalogs in the 49 selected files pass: 137 shapes, 50,076 vertices, 621,631 raw components and 621,631 scaled components. The raw components comprise 412,824 float32 fields and 208,807 integer fields. All 133,872 indices from 137 streams match and lie inside their vertex groups. The comparison also verifies 164 bone references and every preserved shape-position field by bits. Short scalar types have six additional controlled signed/unsigned component checks; the owner components use float32 and byte types.

The 16 scene bindings use 11 unique model resources. Those resources contain 46 shapes, 18,095 vertices and 51,948 indices. Counting records once per bound instance gives 52 shapes, 18,333 vertices and 52,734 indices. Correction to the initial note: its "16 models" count described instances and included repeated assets. The 39-model corpus totals above count each resource once. Face groups include references to bones 0 and 1. The reader retains resource-local data and leaves bone transforms unresolved. Complete primitive fields and skinning fields remain raw numbers.

Retail command builder 0x002B3940 reads only index descriptor byte +4 and maps 0/1/2 through the three-entry table at 0x003AF1C0 to values 4/5/6. The emitted index count and type, triangle-element flags, primitive configuration and draw-elements trigger follow the public [GPU register description](https://www.3dbrew.org/wiki/GPU/Internal_Registers) and [drawing-elements guide](https://www.3dbrew.org/wiki/GPU/Programming_Guide). Its direct caller at 0x002A9DC4 passes a separate geometry override; the examined loader call at 0x001684B4 sets that override to zero. A geometry override changes the command path independently of the serialized byte. The reader therefore reports serialized topology and leaves caller geometry selection unresolved.

Read-only ARM1176 execution in Unicorn 2.1.4 verifies that command builder for all 137 owner descriptors, with zero original-code changes and 19,950 executed instructions including six synthetic mode/override combinations and auxiliary-byte checks. All owner mode bytes are zero; the 133,872 indices describe 44,624 serialized triangle triples. The eleven unique bound resources describe 17,316 such triples, or 17,578 when counted per placement instance. Controlled native fixtures verify triangles, triangle strips and triangle fans using six independently read indices, retaining the complete primitive word while varying its upper bytes. Triangle counts include degenerate primitives; no winding, culling, geometry-shader output or draw-time triangle count is asserted. Unknown mode bytes and incomplete primitive cardinalities reject cleanly.

Retail draw consumer 0x0033549C resolves the CMDL mesh list at +0xB8, selects a shape from the CMDL +0xC8 list using mesh +0x18, and selects a material from the CMDL +0xC0 dictionary using mesh +0x1C. Original block execution from 0x003354C8 through 0x0033556C compares those three resolved addresses against independent raw member reads for every owner mesh. All 137 bindings in 39 models pass, with 5,617 original instructions, read/execute code protection and zero original-code edits. The test uses the resource fallback when the runtime mesh replacement range is empty; replacement paths and subsequent draw/shader calls are outside this check.

The reader retains encoded mesh/material names, object offsets and raw flags. All 137 mesh records have the observed 0x01000000 SOBJ layout and a +0x20 back-reference to their owning CMDL. Their indices stay inside the model's shape list and material dictionary. All 127 material records have MTOB signatures, raw flags 0x08000000 and names matching their dictionary entries. Independent Python reads verify each exposed identity field, index and back-reference; no owner shape or material is unreferenced. Material bodies remain untouched in the original resource. Texture/state interpretation, runtime mesh/material replacement, visibility and animation remain unresolved.

Twenty-eight 0x80000000 vertex groups expose four finite float32 fields inline at +0x20 through +0x2C. All 112 fields match the source bytes by bits. Fifteen normal-semantic records have unit-length first-three values; eleven color-semantic records have four values in [0,1]. The remaining semantic IDs stay numeric. Indirect payload hypotheses failed their bounds and value checks and were rejected. GPU interpretation, replication and fixed-attribute conversion remain unresolved; the reader reports only the observed inline fields.

All 39 models contain a 0x02000000 SOBJ skeleton record. Its dictionary provides 101 joints, with 39 roots and 62 children. The reader retains encoded names, flags, identifiers, parent identifiers/pointers, nine SRT fields and three twelve-field matrices per joint. Independent comparison verifies all 4,545 float32 fields by bits and validates both parent representations and acyclic ancestry. No matrix is applied to a vertex.

The 11 scene-bound resources contain 12 unique joints, or 21 records when counted across the 16 placement instances. Their scale/rotation/translation fields at +0x20/+0x2C/+0x38 reproduce the +0x44 matrix under an independent radians-based Rz * Ry * Rx calculation within 1.65e-8; a degree interpretation differs by up to 0.335928. All twelve matrices at +0x74 remain identity, including two joints with nonidentity +0x44 matrices. The reader therefore exposes matrices by field offset, without assigning runtime roles to them. That numerical relationship supports the raw SRT layout and the fixed-model angle convention; it does not prove pose initialization or draw-time transformation.

Draw-time material state, shape translation semantics, skeleton transforms, animation, caller geometry selection and GPU vertex processing remain open. The owner assets retain unresolved records intact.

Reproduce inspection after local extraction:

```sh
. ./development_environment.sh
clang++ -std=c++20 -Wall -Wextra -Wpedantic -Werror -fsanitize=address,undefined -g runtime/AssetReader.cpp -o build/runtime/asset_reader
python - <<'PY'
import json
from pathlib import Path
import subprocess
directory = Path('data/runtime/romfs')
manifest = json.loads((directory / 'world_one_extraction.json').read_text())
paths = [str(Path('data/runtime/extracted') / item['path']) for item in manifest['files']]
with (directory / 'native_mesh_report.json').open('w') as report:
    subprocess.run(['build/runtime/asset_reader', *paths], stdout=report, check=True)
PY
```
